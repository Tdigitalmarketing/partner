# Checklist de QA — Fase 9

Nenhuma LP é entregue sem passar por todos os itens.

## Responsividade
- [ ] Desktop 1440px+ sem áreas vazias desproporcionais
- [ ] Notebook 1280px
- [ ] Tablet 768px
- [ ] Mobile 390px e 360px
- [ ] Sem overflow horizontal em nenhum breakpoint
- [ ] Fontes legíveis no mobile (corpo ≥ 16px)
- [ ] Áreas de toque ≥ 44px

## Conteúdo
- [ ] Sem erro de português
- [ ] Sem texto placeholder (lorem, "seu texto aqui", etc.)
- [ ] Copy específica do negócio, não genérica
- [ ] Promessas sustentadas por prova
- [ ] Dados de contato corretos

## Conversão
- [ ] CTA visível acima da dobra
- [ ] Oferta clara em até 5 segundos de leitura
- [ ] CTA repetido em pontos estratégicos
- [ ] Link de WhatsApp com mensagem pré-preenchida
- [ ] Formulário validando e com estado de sucesso/erro
- [ ] Nenhum campo desnecessário no formulário

## Links e interações
- [ ] Todos os links funcionam
- [ ] Âncoras rolam para a seção certa
- [ ] Estados hover / focus / active definidos
- [ ] Foco visível no teclado
- [ ] Nada quebra com JS lento

## Visual
- [ ] Espaçamento e alinhamento consistentes
- [ ] Contraste texto/fundo ≥ 4.5:1
- [ ] Hierarquia tipográfica coerente
- [ ] Imagens nítidas, sem distorção
- [ ] Consistência entre seções

## Técnico
- [ ] `<title>` e meta description escritos
- [ ] Open Graph e imagem de compartilhamento
- [ ] `lang="pt-BR"` e viewport
- [ ] Imagens com `alt` descritivo
- [ ] Imagens otimizadas (WebP quando possível) e `loading="lazy"` abaixo da dobra
- [ ] Favicon
- [ ] Nenhum secret ou chave no código
- [ ] Pixel / tag de analytics instalado quando informado
